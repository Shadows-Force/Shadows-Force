# Cómo publicar el portafolio

1. **Perfil:** crea un repositorio público cuyo nombre sea exactamente tu usuario de GitHub. Copia `profile/README.md` como `README.md` dentro de ese repositorio.
2. **Portafolio:** crea otro repositorio público llamado `JekaVSX-Roblox-Backend-Portfolio` y sube todo el contenido de esa carpeta, incluido `src/` y `docs/`.
3. En `profile/README.md`, reemplaza `TU_USUARIO` por tu usuario real de GitHub.
4. Añade tu Discord cuando tengas un enlace que quieras compartir.
5. Lee `NOTAS_PRIVADAS_JekaVSX_NO_SUBIR.md`. Esas notas son para ti; no las copies al repositorio público.

El repositorio de portafolio incluye el código separado en archivos `.luau`. Las dependencias `.cealshell`, `PlayerState` y `cryptography` no se incluyeron porque no venían en el archivo compartido.
