## Sobre mí

Soy scripter de Roblox enfocado principalmente en backend.

Me interesa trabajar con datos de jugadores, sistemas de juego y herramientas de servidor. Prefiero las soluciones simples y prácticas, aprovechando librerías existentes cuando hacen bien su trabajo.

## Lo que trabajo

- Sistemas de datos de jugadores.
- Sistemas de economía y tiendas.
- Inventarios.
- Progresión y recompensas.
- Sistemas de servidor.
- Herramientas y comandos administrativos.
- Optimización y organización de código.
