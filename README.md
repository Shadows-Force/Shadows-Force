# JekaVSX

**Desarrollador backend de Roblox · Luau**

Desarrollo y pruebo sistemas de lógica de servidor para Roblox. Actualmente trabajo en una place privada de pruebas, no en un juego publicado.

## Sistemas

- **Item:** datos, métodos e identidad de objetos.
- **Economy:** operaciones de saldo y monedas.
- **Inventory:** gestión de objetos y cantidades.
- **Shop:** implementación inicial del flujo de compra.
